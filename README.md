# フリーランス ポートフォリオ — AI × 自動化 エンジニア

> Python / TypeScript / LLM API を使った業務自動化・AI エージェント開発のサンプルコード集です。

## 自己紹介

LLM（大規模言語モデル）を活用した自動化システム・AI エージェント開発を専門にしているフリーランスエンジニアです。  
**複数の AI エージェントが安全に協調する設計（ハルシネーション対策・多段ゲート・フォールバック）** が得意領域です。

### 主な個人開発プロジェクト

| プロジェクト | 概要 | 技術スタック |
|-------------|------|------------|
| **Tatara（鑪）** | 複数 AI エージェント（CEO/HR/ワーカー）が協調して自律実行・自己改善する基盤 | TypeScript, Node.js, SQLite, PM2 |
| **Nagi（凪）** | ローカル LLM 4 エージェント構成の自律型 FX 研究システム（多段安全ゲート設計） | Python, MetaTrader5, llama.cpp, LoRA |

## サンプル一覧

### 1. データ分析・月次レポート自動生成

> `data-analysis/` — 売上 CSV を入力に、集計・可視化・Markdown レポート生成を一括実行

- **入力**: 売上 CSV（品目・地域・月次）
- **出力**: 統計サマリ・グラフ（PNG）・洞察付き Markdown レポート
- **技術**: Python, pandas, matplotlib
- **→ [コード・実行手順](./data-analysis/README.md)**

```
Sample Output（実行結果）:
  月次売上推移グラフ ✅
  カテゴリ別・地域別集計 ✅
  相関分析・トップ N 抽出 ✅
  レポート自動生成（report.md） ✅
```

### 2. EC 競合価格スクレイピング

> `web-scraper/` — 複数 URL から商品名・価格を抽出し、価格比較レポートを生成

- **入力**: 対象 URL リスト
- **出力**: 価格比較 CSV・Markdown サマリ
- **技術**: Python, requests, BeautifulSoup4, pandas
- **→ [コード・実行手順](./web-scraper/README.md)**
