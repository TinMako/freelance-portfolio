# フリーランス・ポートフォリオ — Python データ分析 / Web スクレイピング

Python（`pandas` / `matplotlib` / `requests` / `BeautifulSoup`）による
**データ収集・分析・自動レポート生成**の実動サンプル集です。
各サンプルはコード・実行手順・**実際の出力（グラフ PNG / 集計 CSV / Markdown レポート）**を
すべて同梱しており、そのまま `python run_all.py` で再現できます。

## 収録サンプル

### 1. [データ分析レポート生成](./data-analysis/)
合成サンプルの売上データ（800 行・季節性あり）を入力に、記述統計・カテゴリ/地域別集計・
月次時系列・相関分析を行い、**洞察（insights）付きの Markdown レポート**を自動生成します。

- 技術: `pandas` / `matplotlib` / イミュータブル設計
- 実出力例: 月次売上グラフ、カテゴリ別集計、相関行列、トップ N 商品
- 主要インサイト例: Electronics が総売上の **49.9%**・売上は単価と最強相関（**r=0.808**）
- → [コードと実出力を見る](./data-analysis/)

### 2. [Web スクレイパー + 分析 + レポート](./web-scraper/)
公開練習サイト [`quotes.toscrape.com`](https://quotes.toscrape.com) から全 10 ページを巡回収集し
（robots.txt 確認・礼儀的アクセス）、著者別・タグ別に集計してグラフ付きレポートを生成する、
**エンドツーエンドのデータ収集パイプライン**です。

- 技術: `requests` / `BeautifulSoup` / `pandas` / `matplotlib`
- 実出力例: 引用 100 件・著者 50 名・タグ 137 種を収集し集計
- 法務配慮: スクレイピング許可サイトのみ・robots.txt 事前確認・明示 User-Agent
- → [コードと実出力を見る](./web-scraper/)

## 各サンプルの実行方法

```bash
cd data-analysis   # または web-scraper
pip install -r requirements.txt
python run_all.py   # 生成 → 集計 → 可視化 → レポートまで一括
```

実行後、`sample_output/` にグラフ PNG・集計 CSV・`report.md` が出力されます。

## 対応できる作業

- CSV / Excel データの前処理・集計・可視化（売上 / 顧客 / 在庫分析 など）
- グラフ付き Markdown / HTML レポートの自動生成

- 分析結果の解釈（インサイト抽出）と自然言語での説明文生成
