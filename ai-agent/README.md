# AI エージェント — マルチエージェント業務自動化サンプル

> ルーター → アナライザー → サマライザー の **3 エージェント構成**で、  
> 入力内容を自動分類して専門エージェントに振り分けるパイプラインです。

## 設計ポイント

| ポイント | 実装 |
|---------|------|
| **3 エージェント協調** | Router / Analyzer / Summarizer が独立した責務を持つ |
| **多段安全ゲート** | 入力検証（長さ・個人情報フィルタ）+ 出力バリデーション + フォールバック |
| **ハルシネーション対策** | 短すぎる・空の LLM 出力を検出してフォールバックメッセージに差し替え |
| **イミュータブル設計** | `@dataclass(frozen=True)` で副作用なし・デバッグしやすい |
| **差し替え可能な LLM** | `LlmCaller` 型で Anthropic / OpenAI / ローカル LLM を差し替え可能 |
| **モックモード** | API キー不要で動作確認・CI 組み込みが可能 |

## パイプライン図

```
ユーザー入力
     │
     ▼
[入力ゲート] ─── 個人情報・空文字 → BLOCKED（処理中止）
     │
     ▼
[ルーター]  ─── "analysis" / "summary" / "unknown" を分類
     │
 ┌───┴───┐
 ▼       ▼
[分析]  [要約]    （unknown の場合はどちらも呼ばない）
 │       │
 └───┬───┘
     ▼
  出力バリデーション ─── 短すぎる/空 → フォールバック
     │
     ▼
  PipelineResult（route / analysis? / summary? / error?）
```

## ファイル構成

```
ai-agent/
├── agent.py       # エージェント本体（型定義・安全ゲート・パイプライン）
├── run_demo.py    # デモ実行スクリプト（モック / 実 API 両対応）
└── requirements.txt
```

## 実行方法

### モックモード（API キー不要）

```bash
cd ai-agent
python run_demo.py --mock
```

### 実 Anthropic API モード

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY=sk-...   # Windows: $env:ANTHROPIC_API_KEY="sk-..."
python run_demo.py
```

## 実案件への応用

このサンプルのパターンは以下に応用できます。

| 応用例 | 変更箇所 |
|--------|---------|
| FAQ チャットボット | ルーターを「FAQ / 一般問い合わせ / エスカレーション」に変更 |
| 文書処理パイプライン | Analyzer を OCR 抽出 + 構造化に変更 |
| 社内問い合わせ対応 | Summarizer を部署別テンプレート回答生成に変更 |
| データ監視アラート | 入力ゲートに閾値チェックを追加 |
